## Product: Student Launcher

The app's name is **Student Launcher** (a placeholder; it will change again). Every user-facing string, the Android label and its system-service labels, and the platform runners' display names use it; internal channels are `student.launcher/*`. The applicationId (`com.example.launcher`) and Dart package (`launcher`) are unchanged. It was modelled on the real **Yin Yang Launcher** (`com.yinyang.launcher`), which is what "the original" means throughout this file.

An Android home-screen replacement app (light/dark duality) combining a calm home screen, a customizable widget dashboard, and screen-time/wellbeing insights.

Features below are grouped into execution phases, ordered so each phase only depends on ones before it. Update Structure/Commands as each phase lands.

**From-Apps widget pitfalls (if touching this code):** a freshly created `AppWidgetHostView` renders blank for many widgets because their RemoteViews pick a layout by declared size, which defaults to 0×0 dp until told otherwise — `AppWidgetPlatformView` works around this with a one-shot `OnGlobalLayoutListener` that calls the (deprecated but still functional) 5-arg `updateAppWidgetSize` once Flutter's `AndroidView` has a real layout size. `AppWidgetHost.startListening()`/`stopListening()` are wired to `MainActivity.onStart`/`onStop`.

**Weather tile pitfalls (if touching this code):** `LocationAccuracy.low` uses the network/fused provider, which doesn't respond to `adb emu geo fix` on an emulator — use `.high` with a time limit. The `geocoding` package's native reverse-geocode call blocked the Android main thread indefinitely on the test emulator (no Play Services geocoder backend) and caused an ANR; it was replaced with a timeout-bounded HTTP call instead.

**Known limit, not in scope:** Focus Mode can only gate launches this launcher makes. Native From-Apps widget taps (their PendingIntents fire inside `AppWidgetHostView`), notifications, and the recents screen all bypass it. Blocking those would need an `AccessibilityService` or similar app-wide enforcement, which is a much bigger permission ask.

- `lib/settings/` — Settings sheet opened by long-press on Home (Phase 5), the full-screen Settings pages and chooser (`settings_pages.dart`), the Appearance editor, and the Drawer look editor
- `lib/mind_space/` — Mind Space tool UI (Phase 7): the Action tab, the one-time tool explainers, the tool pages, the Mindful Pause overlay, Focus Mode's start sheet and session screen, Mindful Timer's group editor and session-length sheet, Mindful Break's block screen, Focus schedules' list and editor, and the Reflect view
- `lib/search/` — shared app search/filter logic and UI, used by App Drawer, Spotlight Search, and the App Folder/From-Apps picker sheets; `app_picker_sheet.dart` picks one app (App Folder tile, Mindful Break); `visible_apps.dart` applies customizations and breaks to the drawer's and Spotlight's lists; `drawer_apps_view.dart` renders the drawer in any `DrawerLook`; `app_multi_picker_sheet.dart` is the checkbox picker for any set of apps (Focus Mode essentials, and Phase 7's Mindful Pause/Timer/Productive apps)
- `lib/state/` — `AppSettings` (theme incl. Auto, layout, wallpaper per theme, drawer options, gestures) and `launcherTheme`, exposed via `AppSettingsScope` (`InheritedNotifier`)
- `lib/services/` — platform-channel and persistence services (installed apps, onboarding flag, launcher role, My Space tiles, weather, app widgets, usage stats, Focus Mode, Mindful Pause, Mindful Timer, Mindful Break, Focus schedules via `flutter_local_notifications`, productive apps, per-app pins/hides/renames, Home's dock, Home gestures); `installed_apps_service.dart`'s `launch` consults `focus_mode_service.dart` before opening an app — the one choke point all launch call sites (App Drawer, Spotlight Search, App Folder tile) route through
- `lib/models/` — plain data models (`HomeLayoutMode`, `MySpaceTile`, `TileKind`, `Wallpaper` and its catalogue)
- `lib/widgets/` — small shared widgets (`SegmentedToggle`, `WallpaperGallery`, the guided tours' pill/sheet/overlay) and `launchApp`, the UI-side launch helper that explains Focus Mode refusals
- `android/app/src/main/kotlin/.../MainActivity.kt` — native `RoleManager.ROLE_HOME` MethodChannel bridge (`student.launcher/role`: `requestHomeRole`, `isDefaultLauncher`, `openHomeSettings`, `defaultCommsPackages`, `defaultDockPackages`) plus the `student.launcher/app` channel (`restart`, `openAppInfo`, `openClock`, `setStatusBarVisible`); wires up `AppWidgetHostBridge`'s lifecycle/activity-result routing and attaches `UsageStatsBridge` and `MindfulTimerBridge`
- `android/app/src/main/kotlin/.../AppWidgetHostBridge.kt` — native `AppWidgetHost`/`AppWidgetManager` bridge (`student.launcher/appwidget` channel + `student.launcher/appwidget_view` platform view) for the From-Apps tile
- `android/app/src/main/kotlin/.../GesturesBridge.kt` — Home gestures (`student.launcher/gestures`): notification shade via the hidden `StatusBarManager` call, and double-tap lock through `LockAccessibilityService.kt` (lock-only accessibility service) or `LockAdminReceiver.kt` (device admin, force-lock only); their configs are in `res/xml/` and descriptions in `res/values/strings.xml`. `MainActivity.kt`'s `Activity.openExternal` opens any system screen in its own task
- `android/app/src/main/kotlin/.../MusicBridge.kt` — the Music tile's now-playing and transport controls (`student.launcher/music`) via `MediaSessionManager`, enabled by the empty `MediaListenerService.kt` notification listener
- `android/app/src/main/kotlin/.../CalendarBridge.kt` — the Calendar tile's events and `READ_CALENDAR` request (`student.launcher/calendar`)
- `android/app/src/main/kotlin/.../MindfulTimerBridge.kt` — Mindful Timer's in-process session countdown and "Time's up" `SYSTEM_ALERT_WINDOW` overlay (`student.launcher/timer` channel: `canDrawOverlays`, `requestOverlay`, `startSession`)
- `android/app/src/main/kotlin/.../UsageStatsBridge.kt` — native `UsageStatsManager`/`AppOpsManager` bridge (`student.launcher/usage` channel) for Mind Space
- `test/` — widget tests; app startup is async (SharedPreferences), so tests use `SharedPreferences.setMockInitialValues` and `pumpAndSettle`
- `android/`, `ios/`, `macos/`, `linux/`, `windows/`, `web/` — platform runner projects generated by Flutter tooling; rarely need manual edits
- Dart SDK constraint: `^3.13.3` (see `pubspec.yaml`)
- `graphify-out/` — generated knowledge-graph artifacts from `/graphify`; not app code, gitignored
